# FlowBiz · משימה 3 · דפי נחיתה תדמיתיים (מוק-אפ)

מוק-אפ פרונט בלבד (Preact + htm מ-CDN, בלי build) של שדרוג השלב "דף נחיתה בקליק" ועמוד חדש "הדפים שלי".

- השלב: `?screen=opening|data|template|wait|editor|done`
- הדפים שלי: `?view=pages`, דף חדש: `?view=new`, עורך דף: `?view=edit&page=p1`
- הדף כמו שהלקוחות רואים: `?view=public&page=business`
- `?user=f` = דניאלה (לשון נקבה), `?user=m` = דניאל.
- `?embed=1` = תצוגת טלפון. Shift+D = הערות למפתחים ומעבר בין המסכים.

הרצה מקומית: `open-mockup.bat` (פורט 4182). כל הנתונים בדויים.

מסמך המשימה (PDF) נשלח יחד עם הקישור: "FlowBiz - משימה 3 - דפי נחיתה תדמיתיים".
